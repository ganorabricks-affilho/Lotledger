Orders

GET /orders

Orders you received (direction=in) or placed. Optional status / filed filters match the docs.

GET /orders/{order_id}

Full order details (payment, cost, shipping, etc.). Use an order_id from the list response.

GET /orders/{order_id}/items

Line items in batches. Nested lists are order item batches.

Inventory

GET /inventories

List store inventory lots. Filters match the BrickLink docs.

GET /inventories/{inventory_id}

One inventory lot. Use an inventory_id from the list response.

POST /inventories

Create a lot. Body must include item.no, item.type, color_id, quantity, unit_price, new_or_used.

PUT /inventories/{inventory_id}

Update a lot. Quantity must be a delta with + or - (e.g. "+1"), not an absolute set.

DELETE /inventories/{inventory_id}

Delete a lot permanently.
